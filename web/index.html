About LUMINA

A low-light restoration project combining classical computer vision with deep learning.

The problem

Low light means few photons, so images are dark, noisy and colour-shifted. Simply brightening them amplifies the noise along with the signal.

The approach

Analyse each image, run classical and learned restoration, then fuse the results adaptively and validate the output with quality metrics.

Current status

Live system. This interface calls the LUMINA engine on Hugging Face: classical CV, a fine-tuned Zero-DCE++ network and a noise-aware restoration U-Net (v3). Team T76, Computer Vision Hackathon 2026.
